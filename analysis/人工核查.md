# 怎样填写干预核查表

打开 `../CIR_data/reviews/<数据集>/vit_cir-layer6/all/<train 或 val>/base.jsonl`，每行是一条查询。先看修改文本、参考图、正确目标和负候选。CIRR 在对应 split 的 JSON 里用图像 ID 查路径；FashionIQ 图片是 `fashionIQ_dataset/images/<ID>.png`。原始排名、Top-K 和相似度已随行保存。

| 字段 | 填法 |
|---|---|
| `reviewed`、`use` | 看过填 `true`。有明确负样本、视觉因素和合适供体时填 `use=true`，其余填 `false` 并记录原因。每行均需核查。 |
| `negative` | 初值为排在最前的非目标图。若它也满足要求，在同一图库选一个已核实的负样本并填写 ID。CIRR 排除参考图。 |
| `error_type`、`modification_type` | 统一用一套标签，如 `correct`、`violates_edit`、`lost_preserved_detail`、`ambiguous`；修改类型可填 `color`、`background` 等。 |
| `factor`、`condition` | 填被干预的因素，如 `car_color`。文本要求保留该因素填 `keep`，要求修改填 `change`。语义不清可排除。 |
| `donor` | 同一 split、同一类别图库中自然且可比的供体图 ID，须区别于参考图、目标图和负样本。 |
| `box`、`donor_box` | 分别在**原尺寸**参考图和供体图上圈区域，填归一化的 `[左, 上, 右, 下]`。应尽量匹配物体位置、尺度、材质，避免同时改动多个因素。 |

干预先替换局部，再走原始 TargetPad 预处理。程序同时计算同尺寸随机位置替换、同区域涂黑、等幅随机查询方向和参考全局特征置零四个对照。随机位置可能与原区域部分重叠。保留行级结果，检查裁剪是否让标注区域落在可见范围内。每个因素都需要足够的 keep 与 change 样本；按成功、失败各自抽样后的均值仅描述核查子集。

每条数据保留原查询 ID 和目标，train、val 分开填写。两支模型可共用同一批核查对复验 P2。完成 README 的公开模型 val 验收后运行：

```bash
python run.py intervene --dataset both --splits val --backbone release --gpus 8 --temperature 0.07 --layer 6 --limit 0
```

排序风险为 `softplus(-margin / temperature)`，其中 margin 等于目标分数减负样本分数。`necessity` 是替换后风险减原风险。训练对照将监督目标设为 `max(0, necessity)`，拟合新模型替换前后的风险差。它保留原模型中有帮助的依赖，并尝试消除使原排序变差的依赖。这是供 Exp 4 证伪的具体选择。
