# 排序实验

在代码目录执行。先按主 README 准备两个数据集的完整缓存、Combiner 和配对评测结果。以下命令单卡运行，前两步只用训练集拟合系数，排名保存在 `../CIR_data/results/breadth/`。

```bash
python -m analysis.breadth --train-count 1200
python -m analysis.edit_differences --seed 42
python -m analysis.breadth_results
```

`metrics.csv` 含全图库、CIRR 组内和人工核验切片的命中率、配对差值、区间及修好和弄错的条数。可选的 `circus_public_ranks.zip` 存在时还会生成 `external.json`。压缩包取自 [CIRCUS 固定版本](https://github.com/EdinburghNLP/CIRCUS/tree/65dd92fa2f44f1818e4d0f2d44add342f9ce644c/shortcut_audit)，保留 CIRR、FashionIQ、CIRCO 三个 aggregated_best_rank_mm_any JSON。

## PinPoint 公开排名

将 [PinPoint 固定版本](https://github.com/pinterest/pinpoint-dataset/tree/059d6e4ae191d3f0775cbe2e9cf77baa0e714126) 的 `pinpoint_licensed.parquet`、`utils/metrics.py` 和以下六个 `standardized_results/` 文件放在 `../CIR_data/raw/pinpoint_public/` 下，文件平铺即可。整组实验只读排名和人工标注。

- `metaclip2_retrieval_results_combined.json`、`metaclip2_retrieval_results_image_only.json`、`metaclip2_retrieval_results_text_only.json`
- `bge_vl_mllm_s1_retrieval_results_licensed.json`、`bge_vl_mllm_s1_retrieval_results_licensed_reranked.json`
- `gpt5_text_premerge_standardized.json`

```bash
python -m pip install duckdb==1.4.2
python -m analysis.pinpoint_ranks
python -m analysis.pinpoint_folds
python -m analysis.pinpoint_swaps
python -m analysis.pinpoint_ceiling
```

四步分别生成 `pinpoint.json`（固定规则）、`pinpoint_folds.json`（按参考图五折）、`pinpoint_swaps.json`（局部交换）和 `pinpoint_ceiling.json`（用已知标注估算过滤的收益）。目录与原生实验相同。
